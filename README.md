## Submission workflow

The default branch contains course materials. Existing `submission/` branches and `anant-arya-labs` contain separate work; do not delete or combine them without checking their upstream pull requests.

1. Start from the branch required by the course.
2. Complete the notebook and record dataset/dependency requirements.
3. Review outputs and remove only unnecessary generated files.
4. Commit with the lab name and a short summary.
5. Submit through the existing course pull-request workflow.

Notebook dependencies and datasets vary by exercise. Follow the individual lab instructions.
